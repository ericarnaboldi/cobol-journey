# COBOL Journey

Building a new profession in Mainframe application development
--------------------------------------------------------------

I am building a new professional career in **COBOL and Mainframe application development**, with a specific objective: becoming employable in Italy and progressively developing the skills required to work in **application maintenance, analysis and legacy system evolution**.

This repository documents the journey from the foundations of COBOL to a practical understanding of enterprise information systems.

The objective is not simply to learn a programming language.

It is to learn how to **understand, maintain, analyse, test and evolve complex business applications**.

🧪 How I learn
--------------

This repository is based on a practical learning approach:

> **Learn → Build → Test → Analyse → Document → Explain → Improve**

I do not want to measure progress only by courses completed or hours studied.

A skill becomes meaningful when I can:

1. understand it;

2. use it;

3. explain it;

4. troubleshoot it;

5. document it;

6. apply it to a realistic business problem.

📝 Philosophy
-------------

Mainframe systems are not simply old software.

They are long-lived information systems containing decades of business rules, data structures, processes and institutional knowledge.

Learning COBOL therefore means learning to work with **existing systems whose logic matters**.

My objective is to become someone who can understand that logic, work safely within it, and progressively help modernise or evolve it.
