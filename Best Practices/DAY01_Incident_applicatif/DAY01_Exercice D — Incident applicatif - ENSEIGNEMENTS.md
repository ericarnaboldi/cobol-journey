DAY01_Exercice D — Incident applicatif - ENSEIGNEMENTS
Situation : un utilisateur signale que le résultat calculé par le programme semble incorrect pour certains dossiers.

Ton diagnostic pourrait progressivement devenir :
1. Qualifier le ticket : auteur habilité, informations suffisantes.
2. Chercher un incident connu ou déjà traité.
3. Identifier précisément l'application/programme concerné.
4. Identifier l'environnement et la version réellement exécutée.
5. Identifier le ou les dossiers concernés et obtenir un cas concret.
6. Récupérer les données d'entrée exactes.
7. Déterminer le résultat attendu.
8. Reproduire l'exécution avec les mêmes données.
9. Comparer résultat obtenu / résultat attendu et localiser la divergence.
10. Examiner ensuite le code et les règles métier pour déterminer la cause.
